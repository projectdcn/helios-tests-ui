  • SSH key on the machine that runs the tests (this UI server, or the jump host for a jump-host rack), with no passphrase, accepted by every switch and compute tray. Install it with ssh-copy-id. Which key: HELIOS_SSH_KEY on that machine (UI server: config/ui.env), else the inventory's key_file, else the machine's own ~/.ssh setup - so an inventory does not need to name one person's key.
