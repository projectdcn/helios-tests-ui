Every run started here joins the rack's current session (the first run starts one, named by date); the session's consolidated result (the latest result of each test across its runs) is at the top of the Results tab.

Presets and the rack's default form are saved per rack in ui-presets.json / ui-defaults.json of the rack's results folder; the form you last used is remembered in this browser. The form opens with the saved default if there is one, else the form last used in this browser, else the original form. The AFM password is in none of them (it can be kept in the macOS Keychain, below).
