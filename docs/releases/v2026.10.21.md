Offline installer bundles of the helios-tests web UI. Pick one, unpack it and run `./install.sh`
(see README-INSTALL.txt inside). An upgrade keeps `config/` and `data/`; `bin/install.sh --rollback` goes back.

- `helios-ui-v2026.10.21.tar.gz` - Linux x86_64, CPython 3.10 - 3.12
- `helios-ui-v2026.10.21-macos.tar.gz` - macOS arm64 + x86_64, CPython 3.10 - 3.14
- `SHA256SUMS`

## Installer
- The test-plan workbook, inventories and results folder now follow the installation directory. A `racks.yaml`
  restored from a settings backup, or kept after the installation was moved, pointed at the old installation's
  path ("workbook not found"). The starter profile uses `../data/...`. On install / upgrade, `install.sh` rewrites
  paths into another installation's `data/` and keeps `racks.yaml.bak-<time>`.
- A missing configured workbook falls back to the same name in this installation's `data/testplan/`, else the
  only workbook there, under any name.

## Web UI
- Results: tick runs (or select all) and **Clear selected**. They go to a Trash where they can be restored.
  **Delete permanently** per item and **Empty trash** (you type DELETE) remove them for good; each delete is logged
  in `.trash/deleted.log`.
- Results: Rebuild shows its progress and what it rebuilt. Reports of runs in the oldest result layout build again.
- Setup: download the test-plan workbook.

## Test cases
- TC-SWH-063: audit of the lossless (PFC) configuration of the switches.
- TC-SWH-060: incast evidence (every per-port queue table). It is BLOCKED, not "no congestion", when no real
  incast was made or the load was far below line rate.
- TC-E2E-144: pre-flight picks a GPU with all its links up (else BLOCKED). Records switch, tray and AFM views per
  port, before and after the cut.
- TC-CTL-098: reads the alert policy back. Selector keys are readable in the logs.
- Test plan: TC-AFM-005A and TC-AFM-048A get their own IDs (they shared them with TC-AFM-005 / 048).

## Virtual rack
- `tools/vrack.sh` simulates the g02-g17 rack on 127.0.0.1: SSH to every switch and tray, a fake AFM (API and web
  view), Redfish BMCs. It also models QoS profiles, the data path with one-way incast, tray reboots and state.
  Its numbers are modelled, not product results. The installer profile has a `vrack` rack.
